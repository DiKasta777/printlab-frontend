# Интерфейс Print Lab

Главная страница реализована на существующей основе React + TypeScript, без новых зависимостей. Сохранены маршрутизация, ErrorBoundary и правила проверки проекта.

## Готово

- Главный экран по предоставленным скриншотам Figma: геометрия, параметры, результат, график и таблица.
- Светлая и тёмная темы, адаптация к мобильным экранам, подписи полей и клавиатурная навигация.
- Чтение локальных ASCII и бинарных STL до 15 МБ и 100 000 треугольников, проверка координат и размеров.
- Геометрический предпросмотр с поворотом вокруг вертикальной оси, масштабированием и каркасом. Для больших моделей отображается до 1500 граней с уведомлением об упрощении. Это предварительный просмотр, не анализ корректности сетки или пригодности модели для печати. STL не задаёт единицы: размеры показаны в единицах файла.
- Валидация числовых параметров браузером, сообщения об успешной загрузке и ошибках, удаление модели.
- Кнопка «Запустить оптимизацию» пока показывает локальный пример результата. Фиксированные цифры и пример таблицы взяты из предоставленного макета. Поля запроса сохраняются отдельно и не влияют на демонстрационные рекомендации. Изменение формы или модели убирает старый результат.

## Подключение сервера

REST API пока не реализован в просмотренной основной ветке backend. Сетевых запросов и загрузки пользовательских файлов на сервер в этом интерфейсе нет. Нужны согласованные URL загрузки и оптимизации, формат запросов/ответов, ошибки и единицы измерения. После этого заменить showDemo настоящим запросом, вынести API в features/optimization и отображать возвращённые сервером результаты. Демонстрационные числа нельзя использовать для расчёта нагрузок.

По скриншотам видны светлая/тёмная версии и состояния загрузки, но точные размеры, шрифты и исходный логотип из Figma недоступны. Логотип восстановлен в SVG по изображению; для полного совпадения нужен исходный SVG из макета.

## Установка изменений в существующий проект на Windows

1. Работайте в своей ветке dima-practice. Учебную надпись можно не возвращать: новый файл главной страницы заменяет её.
2. Распакуйте printlab-review-update.zip в отдельную папку.
3. Скопируйте из архива каталоги src, e2e и docs в C:\Users\dima0\PrintLab\printlab-frontend, согласившись объединить папки и заменить совпадающие файлы. Другие файлы удалять не нужно. Если в этих файлах уже есть собственные правки, сначала сохраните их копию.
4. Новые пакеты устанавливать не требуется. При работающем npm run dev браузер обновится; иначе запустите npm run dev в папке проекта.
5. Проверьте localhost:5173. Полная проверка: npm run check. Браузерные тесты: npx playwright install chromium, затем npm run test:e2e.
6. Перед отправкой согласуйте номер задачи с куратором и название рабочей ветки по CONTRIBUTING.md. Pull Request фронтенда направляется в main. Архив не отправляет изменения в GitHub автоматически.

## Проверено

`npm run check` проходит: форматирование, ESLint, 21 тест, TypeScript и production-сборка. Сохранены пороги покрытия из исходного проекта. 8 браузерных сценариев проходят на desktop и mobile Chromium, включая Axe в светлой и тёмной темах, загрузку STL и валидацию формы. В среде подготовки использован Chromium 153 с временной конфигурацией запуска; конфигурация CI проекта не менялась. Снимки экрана находятся в docs/screenshots.

## Сверка с итоговыми PNG

Ориентиры: infill-lab-main 1(1).png, 5(1).png и 6(1).png. Обновлены серые панели, бирюзовые и оранжевые контуры, шапка и пропорции блоков. До загрузки файла в области просмотра показана надпись «МОДЕЛЬ». Пункт «Информация…» раскрывает справку о формате. Успешная загрузка и ошибка показываются небольшим уведомлением сверху без затемнения и блокировки страницы. Уведомление закрывается кнопкой или автоматически через 7 секунд. Отдельные чёрные экраны из ранних вариантов не используются.

Для читаемости часть оттенков текста имеет больший контраст, чем в PNG. Реальная геометрия после загрузки сохранена. По замечанию куратора убраны видимые сообщения о демо и недоступном сервере; реальные расчёты ещё не подключены. Данные графика согласованы с таблицей, а не с отличающейся от неё линией на макете. Это реализация по растровому макету, не точная передача размеров и шрифтов из Figma.

После копирования обновления в dima-practice выполните npm.cmd run check, сохраните изменения коммитом «Исправляет отступы и уведомления по замечаниям куратора» и нажмите Sync Changes / Push в VS Code. Уже открытый Pull Request №5 обновится автоматически; новый создавать не нужно.

## Правки куратора

Шапка переименована в Print Lab, надписи о сервере и демо убраны с основного экрана, текст кнопок белый. Оранжевый фон кнопок немного затемнён для читаемости белого текста. Блок результатов уплотнён: график имеет широкие пропорции, значения параметров стоят рядом с подписями, раскрываемые параметры запроса вынесены за рамку. Исправлены подписи осей графика; шкала прочности 0–300 Н соответствует таблице. Проверены ширины 1889, 1440, 1100, 768, 390 и 320 пикселей без горизонтальной прокрутки.
